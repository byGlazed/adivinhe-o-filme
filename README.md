# Qual filme eu estou pensando?

Um jogo interativo em formato de site, inspirado no clássico "20 perguntas", mas com filmes. Você escolhe o modo, define quantas perguntas podem ser feitas e tenta descobrir o filme antes que acabem as tentativas.

## Modos de jogo

1. **Você adivinha**: o site escolhe um filme em segredo. Você faz perguntas de Sim/Não e, quando quiser (ou quando as perguntas acabarem), dá o palpite final.
2. **O site adivinha**: você pensa em um filme e o site faz as perguntas. Você responde Sim, Não ou Não sei, e no fim ele tenta acertar.

Em ambos os modos, o limite de perguntas é configurável.
